# Лабораторна робота №2: Збірка проєкту за допомогою Gradle та Java Collections Framework

## Опис проєкту
Проєкт реалізує аналізатор серверних логів у форматі **Common Log Format (CLF)** на мові Java з використанням стандартного Java Collections Framework (`Set`, `Map`, `List`) без сторонніх бібліотек для роботи з колекціями. Збірка проєкту та керування залежностями налаштовані за допомогою **Gradle (Kotlin DSL)** та **Version Catalog** (`gradle/libs.versions.toml`).

Функціональність класу `LogAnalyzer`:
* `getUniqueIps(List<String> logLines)` — виділяє унікальні коректні IP-адреси з логів, ігноруючи пошкоджені рядки.
* `getTopIps(List<String> logLines, int topN)` — визначає `topN` найчастіших IP-адрес за спаданням частоти із лексикографічним сортуванням (за зростанням) у разі однакової кількості запитів.
